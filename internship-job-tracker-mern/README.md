# Internship Job Tracker (MERN)

## Requirements
- Node.js 18+
- MongoDB Atlas or local MongoDB

## Setup
1. Configure `backend/.env` using `backend/.env.example`.
2. Backend terminal: `cd backend`, `npm install`, `npm run dev`.
3. Frontend terminal: `cd frontend`, `npm install`, `npm run dev`.
4. Open http://localhost:5173.

Do not upload `.env` or database passwords to GitHub.

Features: student registration by roll number, create internship applications, six statuses (Saved, Applied, Online Test, Interview, Offer, Rejected), search, filter, dashboard counts, update status and delete.
